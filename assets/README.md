# Assets

Source-of-truth brand and marketing assets for Fathom. These are working files, not
runtime assets — anything the app serves belongs in `apps/web/public/` or
`apps/web/src/`.

- `logos/` — logo files in their original and exported formats
- `branding/` — brand guidelines, color references, fonts, templates
- `screenshots/` — product screenshots for README, docs, and store listings
